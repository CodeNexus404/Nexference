Backups

Before each apply, the previous ~/.claude/settings.json is copied to ~/.nexference/backups/ with a timestamp.

🔒

Privacy

API keys stay in your browser's localStorage. They are never sent anywhere except the gateway you choose. Config is written through the local server to ~/.claude/settings.json after a backup is made.
